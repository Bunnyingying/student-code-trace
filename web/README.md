# teacher-dashboard 教师可视化面板

这是一个离线运行的教师端可视化面板，用来分析 `code-edit-trace` 插件生成的 `edit-trace.log` 和 `ai-session-trace.log`。

面板不需要 Node、后端、数据库或登录。教师收集学生上交的日志后，直接在浏览器中打开本页面即可使用。

## 文件说明

```text
teacher-dashboard/
├── index.html                  # 单文件可视化面板，主要使用入口
├── edit-trace.log              # 教师测试/验证时使用的一份日志
├── test-data/
│   ├── 张三-edit-trace.log     # 测试用日志
│   ├── 李四-edit-trace.log     # 测试用日志
│   ├── 王五-edit-trace.log     # 测试用日志
│   ├── 张三-ai-session-trace.log  # 测试用 AI 会话日志
│   ├── 李四-ai-session-trace.jsonl  # 测试用旧版 AI 会话日志
│   ├── generate_samples.py     # 生成测试日志的脚本
│   └── verify_dashboard.cjs    # 浏览器端到端验证脚本
└── 副本文件/                    # 历史备份版本，不建议直接使用
```

## 快速开始

1. 安装 `code-edit-trace` 插件，学生完成作业后上交源代码文件夹、`edit-trace.log` 和 `ai-session-trace.log`。
2. 使用 Chrome 或 Edge 双击打开：

   ```text
   teacher-dashboard/index.html
   ```

3. 推荐点击 **“选择文件夹（整班导入）”** 选中某一次课的学生作业文件夹；也可以把日志文件拖入页面，或点击“选择日志文件”。
4. 按页面提示确认课程名称（已自动填好班级文件夹名，可直接确定，也可以改成“第1次课 2026.9.23”这类名称）。
5. 等待导入完成后，页面会显示有效事件数和跳过行数。

也可以使用 VS Code Live Server 打开。如果页面曾经缓存过旧版本，请强制刷新或重启 Live Server。

## 整班导入（推荐）

学生按作业文件夹统一上交时，不需要再逐个拖日志文件：

1. 点击面板上的 **“选择文件夹（整班导入）”**（或把整个文件夹直接拖进面板）。
2. 选中某一次课的学生作业文件夹，例如：

   ```text
   0923 711班实验/
   └── 学生作业[11时3分54秒]/
       ├── [王桦君_2250701_PC01]/01/edit-trace.log
       ├── [王桦君_2250701_PC01]/01/ai-session-trace.log
       └── ...
   ```

3. 如果多次课放在同一个父文件夹下（例如 `过程性数据/`），直接选中父文件夹即可一次导入多次课，系统会按班级文件夹自动拆成不同课程：

   ```text
   过程性数据/
   ├── 0923 711班实验/...   → 课程：0923 711班实验
   └── 0923 10班实验/...    → 课程：0923 10班实验
   ```

整班导入时页面会：

- 递归扫描所选文件夹的全部子目录，自动找出所有 `edit-trace.log`、`ai-session-trace.log`、`ai-session-trace.jsonl`。
- 自动跳过作业网页、`README.md`、`.DS_Store`、`*.log.tmp` 等与日志无关的文件。
- 按学生识别信息自动分人，按班级文件夹自动命名课程。
- 导入结束前统一修复个别学生填错的班级信息。

文件夹层级可以任意深（例如日志放在 `01/`、`新建文件夹/`、`作业提交/` 下都能识别），学生文件夹名建议保持 `[姓名_学号_PCxx]` 格式。

## 学生与课程识别顺序

学生姓名按以下顺序识别，先命中者优先：

1. 日志文件名中的姓名（`张三-edit-trace.log`、`李四_ai-session-trace.log`）。
2. 日志内容里的 `student.name`。
3. 整班导入时学生文件夹名 `[姓名_学号_PCxx]`。
4. 以上都没有时，自动命名为“学生1、学生2……”。

学号和班级优先取日志内容里的 `student.studentId`、`student.className`；内容缺失或明显异常（例如姓名填成“1”）时，会用学生文件夹名和同一次课里其他学生的班级值自动兜底。

课程名称按以下顺序确定：

1. 在课程名称对话框中手动填写的名称（填写后整次导入统一使用该名称）。
2. 整班导入时识别到的班级文件夹名（例如 `0923 711班实验`）。
3. 都没有时使用“未命名课程”。

> 注意：如果选中父文件夹一次导入多次课，而对话框里手动填了名称，则所有课都会用这个统一名称；想按班级分开，直接留空即可，页面会按班级文件夹分别命名。

## 导入日志

- 支持一次拖入多个日志文件，包括代码轨迹和 AI 会话日志。
- 支持同时选择多个 `.log`、`.jsonl`、`.txt` 文件。
- 支持选择或拖入整个文件夹，一次性导入整班日志（见上文“整班导入”）。
- 文件按 UTF-8 解析，空行和损坏 JSON 行会被跳过。
- 学生姓名与课程名称的识别顺序见上文“学生与课程识别顺序”。
- 同一个学生提交了两个文件夹（重复提交）时，两个文件夹的编辑事件都会计入；AI 会话会按 `sessionId` 自动去重。

- AI 会话日志兼容插件 `0.0.5/0.0.6` 的 `ai-session-trace.log` 和 `collect_cline_sessions.py` 生成的旧版 JSONL。
- 导入旧日志时会过滤 `mode_notice`、`file_content` 等系统内容，并按 `sessionId` 合并重复快照。
- 导入结果会显示过滤的系统消息数、合并的重复快照数和时间未校准记录数。
- `ai-session-trace.log.tmp`、`ai-session-trace.log` 和 `edit-trace.log` 自身产生的文件操作记录会被网页分析忽略。

- 导入时会弹出课程名称输入框。可以填写，也可以跳过；跳过时按班级文件夹自动命名，识别不到再使用“未命名课程”。
- 填写过的课程名称会保存在浏览器本地，下次导入时显示为快捷按钮，点击即可自动填充。
- 不同课程会分成不同下拉组，方便管理多个班级或多次作业。
- 导入结果超过 100 个字符时，默认折叠，可点击“展开折叠内容”查看完整信息。

## 左侧学生栏

学生栏按课程分组展示。每个学生有：

- 勾选框：用于选择单个或多个学生。
- 编辑：修改学号、班级、课程名称。
- 删除：从当前导入数据中移除该学生及其相关事件。

顶部“全选”控制当前数据范围：

- 全选：显示全部学生。
- 取消全选：当前不选择任何学生。
- 勾选部分学生：只统计和展示这部分学生。

## 顶部筛选

筛选区支持：

- 课程筛选
- 文件类型筛选
- 操作类型筛选
- 起始日期筛选
- 结束日期筛选
- 文本搜索

文本搜索会搜索：

- 学生姓名
- 课程名称
- 文件路径
- 文件类型和扩展名
- 事件预览中的代码文本

所有页面和导出结果都会跟随当前筛选条件。

## 页面说明

### 可视化分析

“可视化分析”会根据当前勾选的学生数量自动切换内容：

- 0 人：显示“请至少选择一名学生”的空状态。
- 1 人：显示该学生的统计卡、操作类型和文件类型分布、整行修改时间分布图、文件改动明细和编辑时间线；时间分布图点击打开后可缩放，并点击时间柱查看具体操作次数。文件改动明细和编辑时间线均可单独导出 CSV。
- 2 人及以上：显示群体统计、学生编辑次数对比、修改时间分布、操作类型和文件类型分布，并追加多人对比表。

多人下的“编辑量与文件覆盖范围”和“操作类型对比”表格右侧提供“导出表格”按钮。

### 操作明细

“操作明细”包含两个子栏目：

#### 文件操作明细

展示当前筛选范围内的文件汇总，支持：

- 点击列标题排序
- 分页查看
- 导出筛选后的文件汇总 CSV
- 时间分为“年月日”和“具体时刻”两行显示
- 不显示扩展名列

#### 事件操作明细

展示逐条操作事件，包括：

- 时间（年月日为一行，具体时刻为另一行）
- 学生
- 课程
- 文件
- 文件类型
- 操作类型（纵向排列）
- 文本长度
- 预览

点击“预览”文字可以打开完整内容。

事件列表中的预览默认只显示去除空白后的前 10 个有效字符，并追加省略号；点击后仍可查看完整内容。

事件明细的所有列均可点击表头排序。

### AI 问答

展示当前筛选范围内：

- AI 会话总数、提问数、AI 回复数、工具调用数
- Token 输入/输出和总成本
- 学生提问数量对比
- 每个学生的 Token 输入/输出对比
- 学生 AI 使用对比
- AI 会话列表

会话列表采用“学生 → 会话标题 → 提问摘要”的三层抽屉结构。点击提问摘要会打开该会话的完整原文，并自动定位到对应的学生提问。

学生和会话抽屉标题后的箭头表示展开状态：箭头向右表示未展开，箭头向下表示已展开。页面右侧提供“学生 AI 使用对比”和“AI 会话列表”的 CSV 导出按钮。

当导入数据包含 `timeTrusted:false` 或旧版未校时日志时，AI 页面和导出报告会显示“时间未校准”提示。

## 图表交互

- 点击图表卡片会打开页面内放大弹窗。
- 操作类型分布饼图在每个扇区内显示数量，并在右侧显示类别名称。
- 弹窗中可以点击“独立窗口打开”。
- “修改时间分布”弹窗支持放大/缩小，最小可到 1 分钟粒度。
- 点击时间柱可以查看该时间点各学生、操作类型和操作次数。
- AI 页的提问对比和 Token 对比图可点击打开小窗，支持放大/缩小并查看数据明细。

## 导出功能

### 导出报告

点击“导出报告”后可以选择：

- HTML：下载自包含 HTML 报告。
- PDF：打开打印窗口，在打印窗口中选择“另存为 PDF”。
- 报告保留原代码轨迹部分，并在末尾追加 AI 问答汇总、学生提问对比、Token 输入/输出对比、学生对比和逐条会话原文。

### 导出 CSV

- 学生 AI 使用对比：导出 AI 汇总表格 CSV。
- AI 会话列表：按消息逐条导出完整会话 CSV，包含学生提问、对应 AI 回答、工具调用、工具结果和轮次信息。
- 编辑量与文件覆盖范围：导出多人对比表 CSV。
- 操作类型对比：导出各学生操作类型统计 CSV。
- 单学生文件改动明细：导出 `student-file-details.csv`。
- 单学生编辑时间线：导出 `student-edit-timeline.csv`。
- “操作明细 → 文件操作明细”内的“导出筛选数据”：当前筛选后的文件汇总 CSV。
- “操作明细 → 事件操作明细”内的“导出筛选数据”：当前筛选后的逐事件 CSV。

## 日志格式

面板兼容 `code-edit-trace` 插件生成的 JSONL 日志。每条日志是一行 JSON，常用字段包括：

```json
{
  "timestamp": "2026-08-28T01:05:00.000Z",
  "student": {
    "name": "张三",
    "className": "初一1班",
    "studentId": "20260001"
  },
  "eventType": "edit",
  "file": "index.html",
  "changes": [
    {
      "operation": "insert",
      "text": "hello\n"
    }
  ],
  "insertedChars": 6,
  "deletedChars": 0
}
```

同时兼容简化格式中的 `student` 字符串、`rangeLength` 等字段。

AI 会话日志常用字段：

```json
{
  "eventType": "ai.session",
  "sessionId": "ai-s1",
  "student": { "name": "张三", "className": "初一1班", "studentId": "20260001" },
  "title": "制作个人主页",
  "prompt": "请帮我制作个人主页",
  "provider": "deepseek",
  "model": "deepseek-v4-flash",
  "timeTrusted": true,
  "timeSource": "http-date",
  "timeConfidence": "synced",
  "firstQuestionAt": "2026-08-28T01:02:00.000Z",
  "messages": [
    { "role": "user", "type": "text", "text": "请帮我制作个人主页" },
    { "role": "assistant", "type": "text", "text": "好的，我先创建 index.html。" },
    {
      "role": "assistant",
      "type": "tool_use",
      "tool": "write_to_file",
      "inputSummary": "index.html + 个人主页结构",
      "resultPreview": "success"
    }
  ],
  "tokens": { "input": 120, "output": 80, "totalCost": 0.0012 }
}
```

## 数据与隐私

- 页面不会把数据上传到服务器。
- 刷新或关闭页面后，导入的数据会清空。
- 关闭页面时，如果仍存在未保存数据，浏览器会提示先导出。
- 需要长期保存时，请先导出 HTML 报告或 CSV。

## 常见问题

### 直接打开正常，但 Live Server 显示错乱

先强制刷新浏览器。如果仍异常，重启 Live Server，并确认打开的是：

```text
http://127.0.0.1:5500/teacher-dashboard/index.html
```

### 学生姓名识别不正确

面板按“文件名 → 日志内容 `student.name` → 学生文件夹名 `[姓名_学号_PCxx]`”的顺序识别。整班导入时会自动用文件夹名兜底，所以推荐保留学生的作业文件夹结构。

如果单独导入日志文件，建议使用文件名约定：

```text
张三-edit-trace.log
李四_edit-trace.log
```

也可以在导入后点击学生卡片上的“编辑”修改姓名信息。

### 选择文件夹后提示“没有找到日志文件”

- 确认选中的是包含学生作业子文件夹的目录，而不是某一个学生的深层目录。
- 日志文件名需要包含 `edit-trace` 或 `ai-session-trace`，扩展名为 `.log`、`.jsonl`、`.txt`。
- 以 `.tmp` 结尾的临时文件会被忽略，例如 `ai-session-trace.log.tmp`。
- 建议使用 Chrome 或 Edge，部分浏览器对文件夹选择、文件夹拖拽支持不完整。

### 整班导入后学生分错或出现“学生1”

- 优先检查日志内容里的 `student.name` 是否被学生填错（例如填成“1”“张三20260001”）；面板会做保守清洗，清洗失败时用学生文件夹名兜底。
- 学生文件夹名请保持 `[姓名_学号_PCxx]` 格式，否则无法从路径识别。
- 同一个学生名出现在多个文件夹时会被合并成同一名学生；重名同学需要导入后手动“重命名”区分。

### 导入后没有数据

- 确认日志是 UTF-8 编码。
- 确认日志是 JSONL，不是整份 JSON 数组。
- 单独导入名为 `edit-trace.log` 的文件时无法从文件名识别学生（整班导入会用学生文件夹名兜底）；导入后可以点击“编辑”补上姓名。
