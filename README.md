# student-code-trace

课堂场景下的**学生编程行为采集与可视化**工具集，面向教育研究中的学习分析（Learning Analytics）。

## 组成

| 目录 | 内容 | 作用 |
|---|---|---|
| `plugin/` | VS Code 插件（code-edit-trace） | 在学生端 VS Code 中记录代码编辑事件（时间戳、文件、编辑操作），采集过程性行为数据 |
| `web/` | 可视化网页 | 将采集的编辑轨迹转化为行为画像、时间线与交互图表，供教师/研究者查看 |

## 用途

支持编程教育研究，例如计算思维与 AI 协作编程素养的干预效果评估：以客观行为数据与问卷自评互为验证（三角验证）。

## 隐私与合规

- 采集数据默认仅存储于本地/授课环境，**不得推送到本仓库**；
- 发布与使用前请完成学生知情同意与数据脱敏。
